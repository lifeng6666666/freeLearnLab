# 机器学习教程

这是一个完整的机器学习教程，配套提供 **PDF 教材** 和可运行的 **Jupyter Notebook 代码包**。PDF 负责系统讲解理论知识、核心概念、公式和算法伪代码；Notebook 代码配合 PDF 使用，将这些内容落实为可运行的实现、实验和实际应用。

## 教程资料

- [机器学习全面教程（PDF）](机器学习全面教程.pdf)：提供理论、概念讲解、公式、算法伪代码和学习线索。
- Jupyter Notebook 代码：本目录中的 `ch01.ipynb` 至 `ch08.ipynb`，用于跟随 PDF 学习并运行实现、验证和实验。

## 前置知识

本课程面向有一定编程基础、希望理解机器学习原理并动手实现的学习者。开始前建议具备：

- **Python 基础**：变量、函数、类、模块、异常处理和基本文件操作；
- **科学计算工具**：能够阅读和使用 NumPy、Pandas、Matplotlib 的常用操作；
- **数学基础**：高中数学，以及向量、矩阵、导数、概率和统计的基本概念；
- **实验环境**：能够安装 Python 包并运行 Jupyter Notebook。

不要求预先掌握机器学习或复杂的高等数学。课程中涉及的数学会结合算法逐步解释；如果对线性代数或概率不熟悉，可以先把公式和代码作为直觉材料，再回头补充基础。

## 课程大纲

课程按“建立全局认识 → 掌握经典算法 → 理解模型组合 → 进入神经网络 → 学会表示与可视化”的顺序展开：

1. **机器学习全流程**：问题定义、数据集划分、训练与测试、评估指标和基本工作流；
2. **监督学习基础**：线性回归、决策树，以及损失函数、泛化和过拟合等概念；
3. **无监督学习**：K-Means 聚类、异常检测和图像压缩等应用；
4. **集成学习**：随机森林、AdaBoost，以及多个弱模型组合的思想；
5. **间隔与分类**：支持向量机、hinge loss 和线性分类；
6. **神经网络基础**：前向传播、反向传播、梯度下降和手写多层感知机；
7. **降维与表示**：PCA、t-SNE，以及高维数据的压缩与可视化。

## PDF 与代码如何配合

PDF 是教程的理论主线，适合用来理解“为什么这样做”以及算法的整体步骤；Notebook 是配套实践材料，适合用来观察“代码如何实现”和“算法实际表现如何”。建议按以下方式学习：

1. 先阅读 PDF 中对应章节的理论、公式和伪代码。
2. 再打开对应的 Notebook，按顺序运行并阅读代码实现。
3. 对照伪代码与 Python 实现，理解每个步骤在代码中的落点。
4. 运行实验和真实数据案例，观察算法效果，并结合 PDF 回顾结果背后的原因。

## 学习路线

1. 先阅读 PDF 的对应内容，再学习 `ch01.ipynb`，建立机器学习全流程直觉。
2. 按顺序学习 PDF 和 `ch02.ipynb` 至 `ch08.ipynb` 的对应章节。
3. 每章都遵循：PDF 理论与伪代码 → Notebook 从零实现 → 简单数据验证 → `scikit-learn` 对比 → 真实应用。
4. 对比自定义实现与 `scikit-learn` 在精度、速度上的差异，并回到 PDF 思考其原因。

## 后续进阶

完成本课程后，可以沿以下方向继续学习：

- **深度学习**：卷积神经网络、循环神经网络、Transformer、正则化和训练技巧；
- **数学与优化**：多元微积分、概率图模型、凸优化、拉格朗日乘子和数值优化；
- **经典模型扩展**：逻辑回归、朴素贝叶斯、梯度提升树、推荐系统和时间序列；
- **生成式 AI**：词向量、注意力机制、大语言模型、微调、检索增强生成（RAG）和智能体；
- **强化学习**：马尔可夫决策过程、Q-Learning、策略梯度和深度强化学习；
- **工程实践**：特征工程、交叉验证、超参数搜索、模型解释、部署、监控和 MLOps；
- **综合项目**：选择一个真实问题，完成数据收集、清洗、建模、评估、部署和复盘的完整闭环。

建议每进入一个进阶方向，都保留“先理解原理、再实现最小版本、最后使用成熟框架”的学习顺序。
